
# Task 5 - Host a Static Website with GitHub Pages

## Project Overview
This project is part of the Elevate Labs DevOps Internship. The objective is to create, customize, and deploy a static website using HTML, CSS, Git, GitHub, and GitHub Pages.

The website demonstrates how static web content can be hosted online for free using GitHub Pages.

## Objective
- Create a static website using HTML5.
- Customize the website using CSS3.
- Manage source code using Git and GitHub.
- Deploy the website using GitHub Pages.
- Understand the basics of static website hosting.

## Technologies Used
- **HTML5:** Used to structure the webpage.
- **CSS3:** Used for styling, layout, and responsiveness.
- **Git:** Used for version control.
- **GitHub:** Used for source code management and repository hosting.
- **GitHub Pages:** Used for free static website deployment.

## Website Features
- Modern dark-themed user interface.
- Responsive website layout.
- Navigation bar with section links.
- Project introduction section.
- Technologies showcase section.
- Interactive hover effects.
- Mobile-friendly design.

## Deployment Details
The website is deployed using GitHub Pages.

- **Hosting Platform:** GitHub Pages
- **Deployment Branch:** main
- **Publishing Source:** / (root)
- **Protocol:** HTTPS

## Live Website
https://atharv-vyahalkar.github.io/Elevate-Labs-DevOps-Internship-Task5/

## Learning Outcomes
- Understanding static website hosting.
- Learning Git and GitHub version control.
- Configuring GitHub Pages for deployment.
- Understanding branch-based deployment.
- Learning basic HTML and CSS customization.
- Publishing a website publicly without paid hosting services.

## Conclusion
Successfully created and deployed a responsive static website using GitHub Pages. This task provided practical experience with version control, repository management, and free website hosting as part of the DevOps workflow.
