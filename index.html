About This Project

This project is part of my DevOps Internship. The objective is to create a static website using HTML and CSS, manage its source code using Git and GitHub, and deploy it online using GitHub Pages.

Technologies Used

HTML5

Used to structure the website and define its content.

CSS3

Used to style the website and create a responsive layout.

Git & GitHub

Used for version control and source code management.

GitHub Pages

Used to host and publish the static website online.
